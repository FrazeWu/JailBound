# Publication Scope

This repository publishes readable implementation code, command-line scripts,
configuration templates, tests, package metadata, and release documentation.

The following material remains local and is deliberately outside version
control:

- downloaded or source datasets and generated records;
- model weights, caches, checkpoints, and runtime environments;
- experiment outputs, logs, reports, figures, plotting sources, and paper
  materials;
- archives, PDFs, machine-specific configuration, and credentials;
- local planning notes and editor state.

The public implementation is intended to make program structure and interfaces
reviewable. Reproducing a full workflow requires independently obtained data,
models, compute resources, and appropriately configured local services.

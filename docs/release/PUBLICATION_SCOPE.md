# Publication Scope

This repository publishes readable implementation code, command-line scripts,
experiment configurations, tests, package metadata, release documentation, and
content-free aggregate result tables.

The following material remains local and is deliberately outside version
control:

- downloaded or source datasets and generated records;
- model weights, caches, checkpoints, and runtime environments;
- generated prompt and response records, checkpoints, runtime logs, figures,
  plotting sources, and paper source files;
- archives, PDFs, runtime credentials, and private machine configuration;
- local planning notes and editor state.

Tracked experiment configurations may contain path templates from the original
environment. They do not include the referenced data, models, or credentials
and must be adapted before use.

The public implementation and aggregate tables are intended to make the method,
interfaces, and reported comparisons reviewable. Reproducing a full workflow
requires independently obtained data, models, compute resources, and
appropriately configured local services.
